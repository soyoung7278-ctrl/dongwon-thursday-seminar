# 동원 목요세미나 연사 초청 안내

동원그룹과 목요세미나를 외부 연사에게 소개하고, 매월 강연 요청 내용을 전달하기 위한 정적 웹사이트입니다.

## 매월 바꾸는 곳

`content/monthly-brief.js`의 내용만 수정하면 하단의 강연 요청 영역이 자동으로 바뀝니다. 자세한 항목은 `MONTHLY_UPDATE_GUIDE.md`를 참고하세요.

## GitHub Pages 배포

이 저장소의 `main` 브랜치에 변경사항을 올리면 `.github/workflows/pages.yml`이 사이트를 자동 배포합니다.

저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 한 번 선택해야 할 수 있습니다.
